* CRYPTOGRAPHY - is a study of data security it turns plaintext into 
encrypted text and vice versa as a result only receiver or sender can see the 
content 

* cryptography is of two type - 
1. Symmetric crypto - use same key for encryption and decryption

data --> encyption --> secret-key --> decryption --> same secret-key --> data

2. Asymmetric crypto - use two different key for encrypt and decrypt 

keys - private and public 
public key can be shared whereas private key shoulde be secret 

data -> public key -> encrypt -> private key -> decrypt -> data


* Different ways of cryptography -
1. Encoding - change the data into another format
2. Hashing - only one-way transformation, Ex - bcrypt
3. Encryption - hide data + can be decrypt by key
4. signature - prove authenticity, Ex - jwt
