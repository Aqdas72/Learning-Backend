* Mongoose - its a library/tool helps Node.js to communicate with MongoDB
it is an ODM(Object Document Model) library for MongoDB and Node.js

ORM → works with relational databases like MySQL/PostgreSQL
ODM → works with document databases like MongoDB
Mongoose → ODM for MongoDB

* Mongoose gives you things like:

Schema
Validation
Models
Middleware/hooks
Relationships/references
Query helpers
Population
Defaults
Type casting
